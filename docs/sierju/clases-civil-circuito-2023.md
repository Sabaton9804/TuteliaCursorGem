## Notas para el seed SQL

1. `code` en snake_case estable; `label` = texto exacto SIERJU (mayúsculas, tildes).
2. Mismo `code` puede repetirse en secciones distintas → unique `(section_id, code)`.
3. Prioridad mapeo producto → clase para J051: `ejecutivos` oral, `declarativos_verbal_pertenencia`, `insolvencia_persona_natural`.
