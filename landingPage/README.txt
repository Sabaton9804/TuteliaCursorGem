Jurion — Landing page (lista para subir)
=========================================

Contenido de esta carpeta:
  index.html          Página principal (ábrela o súbela como inicio del sitio)
  landing-assets/     Imágenes de capturas de pantalla
  README.txt          Este archivo

Cómo publicar
-------------
1. Sube TODO el contenido de la carpeta landingPage al hosting (FTP, cPanel, Netlify, etc.).
2. Mantén la estructura: index.html y landing-assets/ en el mismo nivel.
3. Si el dominio apunta a una carpeta, coloca index.html como página de inicio.

Vista local
-----------
Abre index.html en el navegador, o desde esta carpeta:
  npx serve .

Notas
-----
- Las fuentes (Inter) se cargan desde Google Fonts; hace falta internet.
- No requiere Node ni build: es HTML estático.
- Para actualizar: edita landing.html en la raíz del proyecto y vuelve a copiar aquí.
